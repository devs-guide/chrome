# Touch diagnostics

Status: planned initial browser laboratory.

This path will provide guided and directly selectable tests for browser/device
identity, secure-context state, Touch Events, Pointer Events, contact count,
gestures, default browser actions, version expectations, and observed behavior.

The application will be a dependency-free offline-capable PWA. Reports stay
local unless explicitly exported.

Public path: `https://devs-guide.github.io/chrome/web/touch/`
