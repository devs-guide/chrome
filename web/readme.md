# Web laboratories

Static browser applications and diagnostics live under capability-oriented
paths. Each implemented feature owns a local README, runtime probe, test
definition, report fields, and public URL.

## Initial namespaces

- [`touch/`](touch/) — initial multi-touch and browser-input diagnostics.
- [`app/`](app/) — general browser application patterns.
- [`extension/`](extension/) — Chrome Extension source, fixtures, and guidance.
- [`pwa/`](pwa/) — installability, service workers, caches, and offline behavior.
- [`rtc/`](rtc/) — browser real-time communication examples.
- [`wasm/`](wasm/) — WebAssembly capability examples.

Only `touch` is in the initial implementation scope. Other paths are navigable
reservations, not claims of working features.

Public path: `https://devs-guide.github.io/chrome/web/`
