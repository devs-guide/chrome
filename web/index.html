Chrome Web Labs

Web laboratories

Static browser applications and diagnostics live under capability-oriented paths. Each implemented feature owns a local README, runtime probe, test definition, report fields, and public URL.

Initial namespaces

  • touch/ — initial multi-touch and browser-input diagnostics.
  • app/ — general browser application patterns.
  • extension/ — Chrome Extension source, fixtures, and guidance.
  • pwa/ — installability, service workers, caches, and offline behavior.
  • rtc/ — browser real-time communication examples.
  • wasm/ — WebAssembly capability examples.

Only touch is in the initial implementation scope. Other paths are navigable reservations, not claims of working features.
