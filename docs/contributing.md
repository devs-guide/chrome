# Contributing

- Read the path-local `readme.md` and selected feature prompt before editing.
- Keep each change focused on one observable outcome.
- Add runtime dependencies only after explicit architecture review.
- Use relative URLs and locally owned assets.
- Never edit `static/` or the generated `www` branch.
- Cite browser edge cases using the repository research authority contract.
- Separate expected support from observed behavior.
- Run repository checks and report their exact results.

Stop before push, publication, Pages settings, merge, tag, release, CA reset,
or target-device trust installation unless explicitly authorized.
