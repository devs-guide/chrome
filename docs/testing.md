# Testing and evidence

Use four evidence layers:

1. repository and static-artifact validation;
2. Python certificate/TLS/static-byte tests;
3. synthetic browser automation;
4. real physical-device validation.

Automation may prove routing, persistence, schemas, event calculations, secure
origin behavior, and offline caching. It may not claim that a physical touch
surface, permission policy, sensor, or vendor-modified browser works.

Every device report records the suite/catalog integrity, origin, reported
identity, observed capabilities, expected limitations, unexpected results, and
evidence classification.
